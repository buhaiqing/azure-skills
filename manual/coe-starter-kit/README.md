# CoE Starter Kit

Operational toolkit for AI Champions and Platform Owners completing the **first week** of an Azure Skills CoE adoption.

## Contents

| File | Purpose |
|------|---------|
| `week-one-checklist.md` | Day-by-day action checklist with DoD and estimated hours |
| `raci-matrix.md` | Role responsibilities across key governance activities |
| `communication-template.md` | Internal announcement template + agent usage policy |
| `success-metrics.md` | KPI definitions aligned with `governance_dashboard.py` |

## Relationship to `adoption-tiers.md`

`adoption-tiers.md` defines **adoption waves and champion responsibilities**. This kit operationalizes those responsibilities into an executable first-week plan. Complete the checklist in `week-one-checklist.md` to satisfy Wave 1 champion obligations.
